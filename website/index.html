  • ✓Declarative Action Engine: Configured via pelid.yaml with slot extraction.
  • ✓100% Destructive Safety: Critical actions (refunds, cancellations) always escalate.

Get Started in 60 Seconds

Drop-in OpenAI Compatibility

Just point your SDK's base_url to Pelid. Zero application changes required.

# Run Pelid Enterprise Gateway with automatic multi-tenant auth
docker run -d \
  -p 8080:8080 \
  -e GEMINI_API_KEY="your-gemini-or-openai-key" \
  -v pelid_data:/app/data \
  adhish/pelid:latest
from openai import OpenAI

# Simply redirect base_url to your local or self-hosted Pelid proxy
client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="pelid_live_your_tenant_key"  # Or your X-Pelid-Key
)

# Intercepted and resolved locally in 28ms for $0.00!
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Where is my order #9921?"}]
)
print(response.choices[0].message.content)
# 1. Issue a new multi-tenant API key
pelid key create --tenant "acme_corp" --name "Acme Corp" --rate-limit 120

# 2. Inspect real-time live cost savings
pelid stats --tenant "acme_corp"

# 3. Start the gateway server
pelid start --host 0.0.0.0 --port 8080
